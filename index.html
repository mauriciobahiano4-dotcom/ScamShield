Tecnologías utilizadas

Herramientas y lenguajes que hicieron posible el desarrollo de ScamShield.

🌐

HTML5

Se utilizó para crear la estructura de las páginas, organizar los contenidos y construir los formularios de cada herramienta.

🎨

CSS3

Se utilizó para diseñar la apariencia visual, aplicar colores, organizar los elementos y adaptar la página a celulares y computadoras.

⚙️

JavaScript

Se utilizó para programar los analizadores, procesar la información ingresada y mostrar los resultados de cada herramienta.

💻

Sublime Text

Se utilizó como editor de código para escribir, modificar y organizar los archivos del proyecto.

📷

HTML5 QR Code

Biblioteca utilizada para acceder a la cámara y permitir la lectura de códigos QR.
